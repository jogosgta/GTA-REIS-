# MEMORY

- The reference link describes Grand Mobile as a mobile open-world RP experience with cars, jobs, homes, NPCs and an online city. GTA REIS uses only the broad genre idea and an original visual identity.
- This session cannot produce a native APK directly; deliver a browser-playable WebDev checkpoint and keep packaging as a follow-up.
- Browser audio requires a user gesture; AudioManager is intentionally procedural and optional.
- Use procedural Babylon meshes for 3D; no external GLB pipeline is required for this first slice.
- The world is now an original São Paulo-inspired city: Centro, Paulista, residential blocks, viaduct, bus, towers, market and garage. It is not a 1:1 geographic recreation.
- Visual performance uses 512px soft shadows, textured façades, a loading gate, and adaptive hardware scaling. Keep post-processing light; full AAA realism would require optimized GLB assets and a larger native pipeline.
- Keep the project frontend-only and avoid server changes.
